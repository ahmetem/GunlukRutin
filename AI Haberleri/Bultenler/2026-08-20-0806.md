## 🟣 Claude & Anthropic

- 🔥 **Claude Code 2.1.236: `ANTHROPIC_DEFAULT_MODEL` değişkeni, macOS sandbox'ta okuma-yasağı sıkılaştırması, auto mode düzeltmeleri** — code.claude.com · 19 Ağustos 2026
  Yeni `ANTHROPIC_DEFAULT_MODEL` ortam değişkeni yeni oturumların hangi modelle başlayacağını belirliyor; `ANTHROPIC_MODEL`'in aksine `/model` ile yapılan seçim bunu ezip yeniden başlatmalar arasında kalıcı oluyor. macOS sandbox'ta `**/.env` gibi joker karakterli okuma-yasağı kuralları artık izin verilen okuma bölgelerinin içinde de öncelikli, eşleşen dizinlerin içeriğini kapsıyor ve yasaklı dosyayı yeniden adlandırarak atlatılamıyor. Auto mode tarafında `Monitor` izin kuralları auto mode etkinken devre dışı bırakılıyor (Monitor komutları artık Bash komutlarıyla aynı incelemeden geçiyor) ve git durum denetimi `status.showUntrackedFiles=no` ayarıyla kandırılamıyor. Ayrıca 2.1.229'dan beri süren "oturumun geçtiği dizin silinince pano kopyalama, arka plan oturumları ve yerel MCP kayıtlarının bozulması" hatası ile 2.1.234'te gelen WSL alt süreç çökmesi düzeltildi.
  **Neden önemli:** Auto mode kullanıyorsan Monitor komutları artık tek tek onay isteyebilir; `Monitor` için tanımladığın izin kuralları auto mode açıkken yok sayılıyor. Sandbox okuma-yasağı kuralların da artık gerçekten bağlayıcı — daha önce izin verilen bölgelerde delinen `.env` benzeri kalıplar bu sürümden sonra kapanıyor.
  https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.237: LLM ağ geçidi kullanan oturumlarda prompt önbelleği düzeltildi, "Concise" çıktı stili eklendi** — code.claude.com · 20 Ağustos 2026
  Bir LLM ağ geçidi ya da özel `base URL` üzerinden çalışan oturumlarda prompt önbelleklemenin bozuk olduğu hata giderildi. Ayrıca yerleşik bir "Concise" çıktı stili geldi: Claude işi aynı özenle yapıp yalnızca sonuçla başlıyor, giriş cümlelerini ve anlatımı atlıyor. `/config` içindeki Output style bölümünden seçiliyor.
  https://code.claude.com/docs/en/changelog

- **Claude API'de Files API, Agent Skills ve Enterprise Admin API genel kullanıma geçti — beta başlığı artık gerekmiyor** — platform.claude.com · 19 Ağustos 2026
  Files API artık GA: `/v1/files` ve dosya referanslayan Messages API istekleri `files-api-2025-04-14` başlığını istemiyor; başlıksız istekler GA yanıt biçimini kullanıyor (yüklerken `expires_in_seconds`, nesnede `expires_at`, `page`/`next_page` sayfalama ve `ids[]` filtresi). Kuruluş başına 1 TB depolama ve dakikada 500 istek sınırı geçerli. Agent Skills ve Skills API (`/v1/skills`) de GA oldu, `skills-2025-10-02` başlığı gereksiz. Claude Enterprise için Admin API'nin kullanıcı yönetimi uçları (üye, davet, grup, özel rol) GA'ya geçti. Aynı gün Managed Agents tarafında `web_search`/`web_fetch` araçlarına `allowed_domains`/`blocked_domains` kısıtı, self-host sandbox oturumlarına bellek deposu bağlama ve Console'da zaman çizelgeli yeni oturum görüntüleyici duyuruldu. Eski beta başlığını göndermeye devam eden istekler değişmeden çalışıyor.
  https://platform.claude.com/docs/en/release-notes/overview
