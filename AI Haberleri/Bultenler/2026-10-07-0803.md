## 🟣 Claude & Anthropic

- 🔥 **Claude Code 2.1.292: MCP protokol 2026-07-28 varsayılan, Agent aracına `effort`, güvenlik düzeltmeleri** — code.claude.com · 6 Ekim 2026
  Yerel (stdio) MCP sunucuları artık tüm kurulumlarda varsayılan olarak 2026-07-28 protokol sürümünü müzakere ediyor; Agent aracına alt ajan efor seviyesi parametresi, `claude plugin install --marketplace` ve 529 geri çekilmesi için `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` eklendi.   **Neden önemli:** Eski protokolde takılan yerel bir MCP sunucun bozulursa `MCP_PROTOCOL_NEGOTIATION=legacy` ile eski davranışa dönebilirsin.
  https://code.claude.com/docs/en/changelog
