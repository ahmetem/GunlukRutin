## 🟣 Claude & Anthropic

- 🔥 **Claude Code 2.1.239: Bedrock'ta sessizce iki kat faturalandırmaya yol açan akış hatası düzeltildi, `/claude-api upgrade` ile Python SDK 1.x geçişi geldi** — code.claude.com · 21 Ağustos 2026
  Sürümün en kritik düzeltmesi Bedrock tarafında: yanıtın `Content-Type` başlığını kaldıran vekil sunucular arkasında akış (streaming) bozuluyor, Claude Code her turu akışsız olarak yeniden çalıştırıyor ve faturalanan API çağrısı sessizce ikiye katlanıyordu. İkinci bir düzeltme, `awsAuthRefresh` ile SSO profili kullanan Bedrock kurulumlarında HTTPS vekili arkasında açılışta takılmayı gideriyor (kimlik bilgisi ön kontrolü artık `HTTPS_PROXY`'ye uyuyor). Yeni `/claude-api upgrade` komutu Python projelerini `anthropic` 0.x'ten 1.x'e taşıyor; skill'in Python referansı da 1.x'e göre güncellendi (zaman aşımları artık `httpx.Timeout` değil `anthropic.Timeout`). Ayrıca maliyet tahminleri (`/cost`, durum satırı, `--max-budget-usd`) veri ikametgahı olan çalışma alanlarındaki 1,1× ABD-içi çıkarım primini de hesaba katıyor; Bedrock, Vertex ve Foundry gibi daha önce dışarıda tutulan kurulumlarda tam ekran işleyici teklifi açıldı ve buralardaki yeni kurulumlar artık tam ekran başlıyor; bulut oturumlarında claude.ai'dan eşitlenen eklentiler `ad@synced` olarak görünüyor; Alpine/musl derlemelerinde görsel yapıştırma, pano ve ses yakalama eklentileri nihayet yükleniyor.
  **Neden önemli:** Vekil sunucu arkasından Bedrock kullanıyorsan bu sürüme kadar API faturanın iki katına çıkmış olma ihtimali var — yükselt ve kullanım kayıtlarını kontrol et. Bedrock/Vertex/Foundry'de yeni kurulumların tam ekran başlaması da davranış değiştiren bir varsayılan.
  https://code.claude.com/docs/en/changelog

## 💻 Öne Çıkan AI GitHub Repoları

- **ruvnet/ruflo** — Claude Code'u çok ajanlı orkestrasyona açan bir "ajan meta-harness"i: 100'den fazla uzmanlaşmış ajan, hiyerarşik koordinasyonlu sürüler, HNSW indeksli kalıcı vektör bellek (AgentDB) ve kurulumlar arası sıfır-güven federasyonu sunuyor. Hem Claude Code eklenti pazarı girdisi hem MCP sunucusu olarak kaydoluyor, böylece ~210 aracı doğrudan Claude Code içinden çağrılabiliyor; güvenlik, test, dokümantasyon gibi alanlarda 35 eklenti ve arka planda çalışan 12 işçi süreç var. MIT lisanslı, TypeScript/Rust.
  https://github.com/ruvnet/ruflo

- **apache/maka** — Yerel öncelikli (local-first) AI ajan çalışma alanı: model etkileşimlerini, araç çağrılarını ve sonuçları yalnızca-ekleme (append-only) olay günlüğüne yazdığı için çalışmalar yeniden üretilebilir ve kaldığı yerden kurtarılabilir. Masaüstü (Electron/React), komut satırı ve değerlendirme araçları ortak bir Runtime Host üzerinden çalışıyor; birden çok model bağlantısı, dosya/kabuk/arama gibi yerel araçlar, izin yönetimi ve artefakt işleme destekliyor. Apache 2.0 lisanslı, TypeScript. macOS Apple Silicon masaüstü derlemesi "erken genel sürüm" olarak işaretli, veri biçimleri ve CLI komutları hâlâ değişebiliyor.
  https://github.com/apache/maka
