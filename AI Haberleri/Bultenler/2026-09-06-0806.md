## 💻 Öne Çıkan AI GitHub Repoları

- **🔥 NVIDIA/SkillSpector** — Claude Code, Codex ve MCP skill'lerini kurulumdan önce tarayan güvenlik analizcisi: 17 kategoride 71 desenle prompt injection, veri sızdırma, yetki yükseltme, tedarik zinciri riski, bellek zehirlenmesi ve MCP araç zehirlenmesi arıyor. CLI (`skillspector scan ./my-skill/`), Docker, Python API ve MCP sunucusu modunda çalışıyor; AST tabanlı tehlikeli kod analizi, taint izleme ve YARA imzaları içeriyor (Apache-2.0, toplam ~16,3k yıldız).
  **Neden önemli:** Dışarıdan skill/plugin kurmadan önce çalıştırılabilecek somut bir kontrol adımı — mevcut `.claude/skills` dizinini bir kez taratmak mantıklı.
  https://github.com/NVIDIA/SkillSpector

- **mksglu/context-mode** — AI kodlama ajanlarında bağlam penceresini optimize eden MCP sunucusu ve CLI aracı. Claude Code, Cursor, Copilot CLI, Gemini CLI dahil 17+ ortamı destekliyor (ELv2, toplam ~20,4k yıldız).
  https://github.com/mksglu/context-mode
