## 🟣 Claude & Anthropic

- 🔥 **Claude API 2026-10-21 sürümü: 2023'ten beri ilk resmi API sürümü (@ClaudeDevs)** — platform.claude.com · 21 Ekim 2026
  Yeni sürümde `temperature`, `top_p` ve `top_k` gönderen istekler 400 hatası alıyor; assistant mesajında doğrudan `document` bloğu ve user mesajında `citations` da artık hata veriyor, Admin API'de `workspace_id` yerine `scope` geldi. Bu sürümü varsayılan gönderen yeni SDK'lar çıktı (Python 2.0.0, TypeScript 1.0.0, Go 2.0.0, `ant` CLI 2.0.0 vb.) ve lisans MIT'den Apache 2.0'a geçti; 2023-06-01 kullanımdan kaldırılmadı.
  **Neden önemli:** SDK'yı yeni major sürüme yükselttiğin an sampling parametresi gönderen kodların 400 almaya başlar; yükseltmeden önce `temperature`/`top_p`/`top_k` kullanımlarını temizle (Claude Code 2.1.307'deki `/claude-api api-version` bu geçişi otomatik yapıyor).
  https://platform.claude.com/docs/en/api/migration-2026-10-21
  https://x.com/ClaudeDevs/status/2113013247209021918

- **Claude Code 2.1.307: checkout hook'larına 30 dk zaman aşımı, safety_event telemetrisi** — code.claude.com · 21 Ekim 2026
  Self-hosted runner'da checkout hook'ları varsayılan olarak 30 dakikada durduruluyor (`--checkout-hook-timeout-min`); izin kuralı, auto mode, hook veya sandbox'ın durdurduğu her araç çağrısı için yeni `claude_code.safety_event` OpenTelemetry olayı eklendi. Ayrıca ayrıştırılamayan araç çağrıları iki kez yeniden deneniyor ve `@claude review stop` ile otomatik Code Review aboneliği kapatılabiliyor.
  https://code.claude.com/docs/en/changelog
