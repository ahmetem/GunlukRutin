## 🟣 Claude & Anthropic

- 🔥 **Anthropic, güvenlik filtresinin çıktı üretmeden engellediği bazı istekleri artık ücretlendiriyor (@ClaudeDevs)** — platform.claude.com · 24 Eylül 2026
  Claude API'de, yanıt başlamadan gelen retler `stop_details.category` değeri `"bio"`, `"frontier_llm"` veya `"reasoning_extraction"` olduğunda artık normal istek gibi, çalışan modelin fiyatından faturalanıyor; akış ortasındaki retler zaten ücretliydi. Diğer kategorilerde çıktısız retler hâlâ ücretsiz, fallback kredisi değişmedi; değişiklik tüm platformlarda geçerli. Anthropic gerekçe olarak son haftalardaki koordineli saldırıları gösteriyor.
  **Neden önemli:** API kullanan akışlarında bu kategorilerde sık ret alıyorsan artık fatura oluşuyor; `stop_details.category` değerlerini izle.
  https://platform.claude.com/docs/en/release-notes/overview
  https://x.com/ClaudeDevs/status/2103170368794185758

- **Claude Code 2.1.282 yayımlandı** — code.claude.com · 24 Eylül 2026
  Geniş terminallerde metin genişliğini sınırlayan `maxProseWidth` ayarı ve yok sayılan telemetri değişkenlerini listeleyen başlangıç uyarısı eklendi. Çözülemeyen web arama sonuçları yüzünden her isteğin 400 vermesi, `--continue`/`--resume` ile genişletilmiş düşünmenin kaybolması ve "Invalid `data` in `redacted_thinking` block" hatası düzeltildi; Bash artık dolu disk kotasını "Exit code 1" arkasına gizlemiyor.
  https://code.claude.com/docs/en/changelog
