## 🟣 Claude & Anthropic

- 🔥 **Claude Code 2.1.314: yazma sınırı ayarı, FORCE_HYPERLINK düzeltmesi, boşta sıkıştırma** — code.claude.com · 30 Ekim 2026
  Yeni `permissions.blockWritesOutsideWorkingDirectories` ayarı, Write/Edit/NotebookEdit araçlarının her izin modunda çalışma dizinleri dışına yazmasını engelliyor. `FORCE_HYPERLINK=false/no/off` artık bağlantıları gerçekten kapatıyor (önceden açıyordu). 200K token üstü boşta kalan konuşmalar VS Code ve Desktop'ta otomatik özetleniyor. Bulut oturumları da kurulum betiği hata verse bile başlıyor.
  **Neden önemli:** `FORCE_HYPERLINK=false` kullanıyorsan davranış tersine döndü. Bulut rutinlerinde setup script hatası artık oturumu durdurmuyor, hatalar sessizce geçebilir.
  https://code.claude.com/docs/en/changelog

- **Claude API: istek sınırı 32 MB'tan 128 MB'a, yeni Usage and Cost Analytics API (beta)** — platform.claude.com · 28–29 Ekim 2026
  Messages ve Token Counting API'lerinde azami istek boyutu 4 kat arttı. Böylece çok görselli computer-use oturumları ve büyük PDF'ler artık 32 MB'ta takılmıyor. Ayrıca model, workspace, API anahtarı ve kullanıcıya göre kırılım veren yeni analitik API beta olarak çıktı. Eski Usage and Cost API "legacy" durumuna geçti ama desteklenmeye devam ediyor.
  https://platform.claude.com/docs/en/release-notes/overview
  https://x.com/ClaudeDevs/status/2115923971279614171

- **Claude kendi konuşmalarında kötüye kullanımı işaretliyor: "self-assessment" (@AnthropicAI)** — safeguards.anthropic.com · 29 Ekim 2026
  Claude her yanıttan sonra konuşmanın güvenliğine dair kısa bir JSON değerlendirmesi üretiyor. Bu değerlendirme gerçek zamanlı engelleme yapmıyor, insan incelemesini besliyor. Fable 5'te %1 yanlış pozitif oranında, güçlü sınıflandırıcının yakaladığı konuşmaların %78'ini, yüksek öncelikli olanların ise %94'ünü yakalıyor. Çıkarım maliyetine eklediği yük %2'nin altında.
  https://safeguards.anthropic.com/2026/self-assessment
  https://x.com/AnthropicAI/status/2115871889549865429
