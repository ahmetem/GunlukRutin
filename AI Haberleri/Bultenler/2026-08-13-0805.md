## 🟣 Claude & Anthropic

- 🔥 **Claude Code 2.1.229: sunucu tarafından verilen hook desteği, `/commit-push-pr` artık tehlikeli git bayraklarını otomatik onaylamıyor** — code.claude.com · 12 Ağustos 2026
  Sürüm, self-hosted runner oturumları için sunucudan gelen hook'ları destekliyor ve `claude remote-control --continue` ile Remote Control oturumlarını sürdürmeyi belgeliyor. Gateway akışına idle timeout'u önleyen SSE keepalive ping'i eklendi; uzun yanıtların akış sırasında kısmen kaybolması, dar terminalde RangeError çökmeleri, Windows UNC/uzun yol sorunları ve 32 MB API sınırını aşan konuşmaların yeniden denenmeden düşmesi giderildi.
  **Neden önemli:** İki davranış değişikliği var — `/commit-push-pr` tehlikeli git bayraklarını artık otomatik onaylamıyor ve self-hosted runner'ın Windows başlangıcı açıkça `--base-dir` istiyor; mevcut runner betiklerin bu bayrak olmadan başlamayacak.
  https://code.claude.com/docs/en/changelog
