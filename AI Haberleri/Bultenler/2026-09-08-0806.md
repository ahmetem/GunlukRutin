## 💻 Öne Çıkan AI GitHub Repoları

- **🔥 1jehuang/jcode** — Kaynak tüketimine odaklanmış terminal tabanlı bir AI kodlama ajanı harness'i; depodaki karşılaştırmada gömülü modellerle 27,8 MB temel RAM kullanımı (rakiplerde 140–386 MB) ve 14 ms ilk kare süresi veriliyor. Vektör gömmelerine dayalı semantik hafıza, paralel görevler için "Swarm" çoklu ajan modu, yan panelli ve mermaid diyagramı çizebilen zengin bir TUI, Firefox üzerinden tarayıcı otomasyonu, oturum kalıcılığı ve harness'ler arası oturum devralma sunuyor. Claude, OpenAI, GitHub Copilot, Gemini, Azure OpenAI, Alibaba Cloud ve OpenRouter gibi sağlayıcıların yanında Ollama ve LM Studio ile yerel modelleri de destekliyor; Linux, macOS ve Windows için kurulum script'leri var, MIT lisanslı (toplam ~19,3k yıldız, bugün +74).
  https://github.com/1jehuang/jcode

- **jo-inc/camofox-browser** — Camoufox (bir Firefox fork'u) üzerine kurulu, AI ajanları için REST API sunan headless tarayıcı; parmak izi sahteciliğini JavaScript katmanında değil C++ motor seviyesinde yaptığını, böylece Playwright ve headless Chrome'un takıldığı bot tespit katmanlarını geçtiğini söylüyor. Kırılgan CSS seçicileri yerine kararlı eleman referansları (e1, e2, e3), ham HTML'e göre yaklaşık %90 daha küçük erişilebilirlik anlık görüntüleri, kullanıcı başına izole çerez/depolama oturumları ve isteğe bağlı kalıcılık sağlıyor. Tarayıcıyı tembel başlatıp boşta kapatarak atıl durumda ~40 MB bellekte kalıyor; proxy çıkışına göre otomatik dil/saat dilimi eşleme, oturum bazlı Playwright trace kaydı, `@google_search` gibi arama makroları ve yt-dlp ile YouTube altyazısı çekme içeriyor, MIT lisanslı (toplam ~9,9k yıldız, bugün +135).
  https://github.com/jo-inc/camofox-browser

- **entireio/cli** — AI ajan oturumlarını git akışının içine yerleştiren bir komut satırı aracı: promptları, yanıtları ve dosya değişikliklerini commit'lerin yanına kaydederek bir kod değişikliğinin nasıl üretildiğini aranabilir hale getiriyor. Kaydedilen noktalardan işe devam etmeyi sağlayan checkpoint sistemi, eşzamanlı oturum ve git worktree desteği var; kendi dalınıza commit atmadığı için git geçmişini kirletmiyor. Claude Code, Codex, Copilot CLI, Cursor, Factory AI Droid, Gemini CLI, OpenCode ve Pi ile çalışıyor; CLI MIT lisanslı, ancak kimlik doğrulama ve "control plane" komutlarıyla yönetilen bir servise bağlı (toplam ~5,1k yıldız, bugün +7).
  https://github.com/entireio/cli
